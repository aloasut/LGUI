# LGUI 作为游戏 UI 框架的高级能力

LGUI 用「一个界面源（`ui/`，FairyGUI 格式）分产多引擎包」的方式替代 FGUI 工作流：网页、Unity、Cocos Creator 与 headless 测试后端共用同一份界面与游戏代码。本文列出它作为**游戏 UI** 框架的高级能力——每条都是用户能感知的行为，细节以对应规范为准（[ui-spec.md](ui-spec.md)、[mvc-spec.md](mvc-spec.md)、[error-codes.md](error-codes.md)、[unity.md](unity.md)、[cocos.md](cocos.md)）。

## 单源多端与一致性

- **单源分产**：`ui/` 一个源按后端分产网页包、Unity 包（PuerTS）、Cocos Creator 包（fairygui-cc bundle）、headless 描述与控件 TS 类型；每次全量重新生成，不存在局部更新。
- **四端一致性测试**：headless 快照为基准，h5 与 Cocos Creator 的一致性运行器（15 个用例）与 headless **逐字段深比较**；输入操作（点击/拖拽/打字/滑条/下拉框/滚轮）各端用真实输入事件走完整链路。
- **引擎无关手感**：点击、双击、长按、拖拽、滑动、缩放等手势由框架统一识别（后端只上报原始输入），阈值三端同一把尺子。

## 界面栈与生命周期

- **五层界面栈**：hud / page / popup / modal / toast；激活语义（modal 打开时下层停用）、遮挡语义（全屏界面盖住下层时其定时器与动效暂停、露出恢复）、modal 按申请顺序排队。
- **包按需加载**：界面包按引用闭包自动加载，无人引用立即卸载，公共包常驻。
- **自动清理**：View 的绑定订阅、定时器、事件、动效全部登记在作用域，关闭自动清理，不做也能不漏。

## 横竖屏与适配

- **换版不写判断**：方向由框架按屏幕尺寸防抖决定；竖屏自动换用 `@portrait` 组件，**同一个 View 实例**重新绑定，列表滚动位置与选中状态保留；游戏代码里写方向判断会被 `lgui check` 拦下。
- **安全区**：刘海等屏幕内边距注入后界面重排，同一帧的尺寸与边距变化合并通知。
- **跨包引用**：子组件与图片可跨包引用，依赖闭包在打开界面时自动加载。

## 动效

- **Transition 动效**：编辑器里做的动效（tween/yoyo/循环/多目标）在各端原样执行；绑定表用 `playing`/`play`/`done` 三个词驱动，界面被遮挡自动暂停、露出恢复。
- **序列帧**：MovieClip 组件，`playing` 与当前帧进绑定表。

## 输入与文本

- **输入框语义**：组字期间（IME）不误报，选完通知一次；Model 值回写输入框时光标不被打扰；maxLength 三端一致。
- **虚拟列表滚动**：写入滚动位置立即提交，换版/换语言保留位置与选中。

## 游戏特性

- **拖放**：`dragData`/`drop` 声明式跨控件拖放，落点由命中测试决定，只认激活界面里可用的控件。
- **红点**：`redDot` 绑定，红点状态跟 Model。
- **艺术字**：ArtText 把数字/文字渲染成美术字（伤害数字、货币），按批次生成与释放。
- **声音**：按钮音按 `ui/` 里按钮的配置、背景音乐按 View 的 `static music`、代码用 `lgui.sound.play`；声道音量持久化，Unity 端换曲淡入淡出、切后台一起暂停。
- **i18n**：文本表扁平键值，复数用 `Intl.PluralRules`（中日韩不区分单复数）；数字缩写与日期格式三端用同一套内置规则，不依赖宿主 `Intl`，保证显示一致。

## 失败语义

- 错误一律带错误码三元组（code / message / next），码表见 [error-codes.md](error-codes.md)；不悄悄兜底：找不到键、请求失败、包缺失都有明确的下一步指引；正式构建下单点失败不拖垮界面其余部分。

## 开发与验证工具链

- **命令行**：`lgui check`（规范校验）、`lgui test`（headless 测试）、`lgui verify`（横竖屏标准截图）、`lgui new module/view`（骨架生成）、`lgui i18n extract`、`lgui art split/cut`（AI 生成图拆包入 ui/）。
- **MCP 工具面**（`lgui-cocos-mcp/mcp/server.mjs`）：把上述能力包装成 MCP 工具，配合 Cocos Creator 编辑器内的 funplay MCP（预览/截图/运行时检查），AI 助手可在对话里完成「改界面 → 校验 → 验证 → 导出 → 引擎里预览」的全流程。
- **headless 后端**：不渲染可测——业务数据、控件属性、界面栈快照在假时钟下确定性输出，`t.*` 操作语义（点击/拖拽/打字/滑条/下拉框/安全区注入）与真实后端一致。
